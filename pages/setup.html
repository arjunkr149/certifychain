🔧 Server Setup

To enable AI certificate analysis, the local proxy server must be running with your Anthropic API key.

Checking server status...
1

Download Node.js

If not installed, download from nodejs.org (LTS version)

2

Get Anthropic API Key

Go to console.anthropic.com → API Keys → Create Key (starts with sk-ant-...)

3

Open terminal in project folder

Windows: Right-click in folder → "Open in Terminal"
Or: Win+R → cmd → cd path/to/certifychain

4

Run the server

Type this command and press Enter:

node server.js

It will ask for your API key — paste it and press Enter

5

Open in browser

Visit: http://localhost:3000

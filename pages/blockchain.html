How Our Blockchain Works

01

Certificate Registered

When a certificate is issued, student data (name, course, date, grade) is combined and a SHA-256 hash is generated.

02

Block Created

A new block is created containing: the certificate hash, the previous block's hash, and a timestamp.

03

Chain Linked

The block is appended to the chain. If anyone tampers with data, the hash changes and the chain is broken.

04

Verification

To verify, we recompute the hash and compare it to the stored value. A match = authentic. Mismatch = fraud.

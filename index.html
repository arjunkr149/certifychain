Frequently Asked Questions

How is this tamper-proof?

Hash chaining records all certificate changes — every certificate is linked to the previous one via SHA-256 hashing. Any modification immediately breaks the chain and is detected.

Who can issue certificates?

Only authenticated admins — colleges, authorities — can create new certificate records through the secure admin dashboard.

Is my data safe?

All passwords are hashed using BCrypt. Personal data is never shared with third parties. We follow GDPR-compliant data practices.

How do I verify with a QR code?

Simply upload the QR code image on the Verify page. Our system decodes it and checks the embedded certificate number against the blockchain database.

Can I use the AI assistant for verification?

Yes! The AI assistant (powered by Claude) can analyze certificate details you paste and provide a fraud-risk assessment and verification guidance.
